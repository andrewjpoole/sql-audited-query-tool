### Key Decisions

1. **SHOWPLAN_XML validation:** Uses `SET SHOWPLAN_XML ON` to generate execution plans without executing statements. Works safely on readonly connections.
2. **Separate validation rules:** SimulationService allows UPDATE/INSERT/DELETE (rejected by SqlQueryExecutor) but blocks DROP/TRUNCATE/ALTER/CREATE/EXEC.
3. **Service architecture:** `ScriptGeneratorService` placed in Database project (not Core) because it depends on `Microsoft.Extensions.Options`.
4. **Three-layer defense:** Keyword validation + SHOWPLAN_XML + ReadOnly connection prevents accidental writes.
